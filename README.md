# Vehicle Service & Maintenance Management System

## 1. Project Introduction

The Vehicle Service & Maintenance Management System is a mobile-based application designed for independent car workshops. The system aims to improve workshop operations by managing customers, vehicles, service appointments, maintenance records, spare parts inventory and payments.

## 2. Project Objectives

- Improve workshop management efficiency.
- Simplify service appointment and maintenance management.
- Improve spare parts inventory management.
- Provide better transparency in service costs and payments.

## 3. Technology Stack

- **Programming Language:** Python
- **Frontend:** Flet
- **Backend:** Flask
- **Database:** MySQL
- **Development Environment:** Visual Studio Code

## 4. System Modules

1. Customer Management
2. Vehicle Management
3. Service Appointment Management
4. Maintenance Management
5. Spare Parts Inventory Management
6. Payment Management

## 5. Unique Features

- Vehicle Service History
- Automatic Service Cost Calculation
- Low Stock Alert
